# Spiraling: pitch presentation

The live pitch deck for **Spiraling**, a first-person dark fantasy horror game concept (university project).

View it at https://kaity-designer.github.io/spiraling-deck/

- Game concept by Kait, Katia and Yannis.
- Every picture, including the closing film, is hand-drawn by Katia.
- Voices are ElevenLabs placeholders for this pitch; the finished game will use real voice actors.
